# QianYe SSH Pilot · 智能运维管家

作者：Qian Ye

Windows 桌面端的 SSH 服务器管理工具：服务器与终端、密钥与授权、TLS 证书集中同步、服务与脚本批量运维，以及一个会自我学习的 AI 运维助手。编译产物是单个 `QianYeSSHPilot.exe`，双击即可运行，无需安装 Go / Node 等任何环境。

窗口的宽度和高度可以随意调整（最小 480 × 360）：和普通的 Windows 窗口一样，把鼠标移到窗口的边缘或四个角，指针变成双向箭头后按住拖动；双击标题栏最大化或还原。界面会跟着窗口大小重新排布：窗口变窄时侧栏先收成图标栏，再窄就收进标题栏左侧的菜单按钮里；程序会记住上次关闭时的窗口大小。

## 功能

**服务器与终端**
- 添加服务器：自定义 SSH 端口（默认 22）、用户名（默认 root）、私钥或密码登录、分组与标签、跳板机（ProxyJump）或代理、非 root 用户的 sudo 提权
- 连接线路：每台服务器可以直连、经跳板机，或经代理连接——本地代理（这台电脑上的 Clash、v2rayN 等，端口可以自动查找，HTTP 还是 SOCKS5 自动识别）、HTTP 代理、SOCKS5 代理，后两种支持用户名密码
- 直连不通时临时换线路：服务器显示「不可达」时点「换线路」（终端连接失败时工具栏上也有），选一台跳板机或一个代理就能连上。临时线路不改服务器的设置，通过它打开的终端和文件管理窗口全部关闭后自动取消；想一直这样连就打开「记住这条线路」
- 保存的登录密码不再隐藏：编辑服务器时直接显示并可以复制，服务器卡片的菜单里有「复制密码」，详情的「连接信息」里也能看到
- 连上服务器后（打开终端、文件管理、测试连接、查看详情都算）自动识别并显示系统名称；程序不会为了识别系统去登录没有连接过的服务器
- 首次连接记录主机密钥（TOFU），之后密钥变化会拒绝连接以防中间人攻击
- 添加服务器时可以直接粘贴 `ssh -p 2222 root@1.2.3.4` 或 `root@host:2222`，自动拆分出地址、用户和端口
- 密码登录的服务器可以「一键改用密钥」：生成密钥 → 部署公钥 → 验证能登录 → 切换，失败不改动任何配置
- 多标签终端（xterm.js）：在终端里点右键弹出菜单（复制、粘贴、全选、查找、清空屏幕、让 AI 分析），字号与配色可调
- 终端快捷键可以在「设置 → 终端」里自定义，默认 Ctrl+Shift+C 复制、Ctrl+Shift+V 粘贴、Ctrl+Shift+F 查找；另外保留 Windows 的习惯（Ctrl+V 粘贴，选中了文字时 Ctrl+C 是复制），可以关闭
- 终端旁边的「AI 运维」面板：直接和 AI 对话，让它操作当前这台服务器（见下文）。面板和终端并排时，终端至少保留约 60 列的宽度，放不下就让面板盖在终端上面，不会把终端挤得很窄
- 拖动分隔条或窗口边框时，终端等停下来再按新的宽度重排一次，并按顺序把新的行列数告诉服务器，避免 Shell 重画命令行时错位
- 服务器详情：CPU / 内存 / 磁盘 / 负载 / 失败服务 / Top 进程，CPU、内存、网络带实时趋势图
- Ctrl+K 全局搜索，快速连接任意服务器、执行快捷命令

**快捷命令**
- 终端右侧的快捷命令面板：点一下就把命令发送到当前终端，可按分组整理、搜索、排序，自带一组常用命令，全部可以修改或删除。分组默认折叠，点开哪个看哪个；搜索时自动展开
- 命令里用 `{{名称}}` 或 `{{名称:默认值}}` 留出使用时再填的内容，例如 `systemctl restart {{服务名:nginx}}`
- 每条命令可以设置「发送后自动回车」和「执行前先确认」；重启、删除这类命令新建时会自动建议开启确认
- 「同时发送到全部终端」一次操作多台服务器；也可以不开终端，选择服务器批量执行并查看每台的输出
- AI 回复里的命令可以一键「存为快捷命令」

**文件管理（SFTP）**
- 每台服务器的文件管理在独立的窗口里打开，可以和终端并排使用；同一台服务器再点一次会切换到已经打开的窗口
- 像资源管理器一样浏览服务器上的文件：路径栏、上一级、主目录、常用位置（/etc、/var/log 等），可排序、筛选、显示隐藏文件
- 拖拽上传：把文件或文件夹从资源管理器拖进窗口就开始上传。拖到某个文件夹那一行上就传进那个文件夹，否则传到当前目录；文件夹连同里面的内容一起上传，服务器上没有的文件夹会自动创建
- 也可以点按钮选择文件或文件夹上传，下载选中的文件与文件夹；底部的传输任务显示进度、速度和剩余时间，可以随时取消
- 传输没有结束时关闭窗口会先询问；主窗口关闭后，还在传输的文件管理窗口会等传输结束再自动关闭
- 上传时目标目录已有同名项目会先询问是否覆盖；下载时本地已有同名文件会自动改名，不覆盖
- 在线查看和编辑文本文件（2 MB 以内），Nginx / YAML / JSON / Shell 等配置带语法高亮，Ctrl+S 保存；保存时先写临时文件再替换，并保留原来的权限与属主
- 新建文件夹 / 文件、重命名、删除、勾选式修改权限
- 以登录用户的身份访问。非 root 用户启用了 sudo 时，没有权限的文本文件会自动改用 sudo 读取和保存（60 KB 以内）；其余操作仍受登录用户的权限限制
- 入口：终端工具栏的「文件」、服务器卡片菜单、侧栏「文件管理」（选择服务器）

**实时监控**
- 只监控已经打开终端（SSH 已连接）的服务器，不会为了监控去连接其他服务器；关闭终端后自动停止
- 「实时监控」页面按卡片显示这些服务器的 CPU、内存、磁盘、负载与网络速率，带迷你趋势图，可按分组筛选、按 CPU / 内存排序、暂停
- 刷新间隔可选 1 / 2 / 3 / 5 / 10 / 30 秒（页面顶部或「设置 → 通用」），也可以整体关闭
- 仪表盘的服务器列表、服务器详情里，打开了终端的服务器同样实时更新
- 资源占用很小：每台服务器只占用一个 SSH 会话，远端是一个只读取 `/proc` 的 shell 循环；只有打开这些页面时才采样，离开后自动停止
- 登录失败的服务器不会自动重试（避免触发服务器的防暴力破解封禁），修正配置或点「重试」后恢复

**密钥管理**
- 生成 ED25519 / RSA 4096 / ECDSA 密钥对，导入 OpenSSH、PKCS#1、PKCS#8 私钥（支持口令）
- 公钥一键部署到多台服务器的 `authorized_keys`（自动修正权限、已存在则跳过），并记录绑定关系
- 扫描服务器 `authorized_keys` 与本地公钥库对账，标记未知来源的公钥，可一键移除
- 安全的密钥轮换：部署新公钥 → 用新密钥验证登录 → 切换配置 → 可选移除旧公钥（验证失败不会改动任何配置）
- 防止误删当前登录公钥

**证书中心（快速更换 / 同步 / 重启服务）**
- 导入证书：粘贴 PEM、选择文件，或从服务器（例如运行 certbot 的机器）拉取；自动排序证书链、校验私钥匹配
- 部署目标：内置 Nginx / Apache / HAProxy（合并 PEM）/ XBoard 节点（xboard-node，部署后自动重启）预设，可自定义路径、权限、属主、检测命令、重载服务、后置命令
- 一键同步到所有目标，每个目标依次：备份旧文件 → 上传 → SHA-256 校验 → 配置检测（如 `nginx -t`）→ reload/restart 服务 → 从本机做 TLS 线上验证；任何一步失败自动回滚
- 续期流程：「更新证书」或「从源刷新」获取新证书后，一键同步到全部服务器
- 自动同步（按证书开启）：每 6 小时检查一次来源服务器（例如运行 certbot 的机器），证书续期后自动拉取并同步到还没更新的部署目标；同一版本部署失败的目标不会反复重试。需要保持 QianYe SSH Pilot 运行
- 扫描服务器：解析 `nginx -T`、Apache、HAProxy 配置、XBoard 节点的 `/etc/xboard-node/config.yml`（`cert_file` / `key_file`）和 `/etc/letsencrypt/live`，自动发现证书路径并添加为部署目标
- 线上检测：查看任意 host:port 实际返回的证书、信任状态与到期时间

**服务与脚本**
- systemd 服务管理：启动 / 停止 / 重启 / 重载 / 开机启动，状态与日志查看，多服务器批量操作
- 脚本库：内置 13 个常用运维脚本，支持参数（环境变量）、bash / sh / python3，批量执行实时输出，执行历史
- 智能巡检：并发采集指标，检查磁盘、内存、Swap、负载、失败服务、证书到期与同步状态、密码登录等，给出健康分和带一键操作的建议
- 自动巡检：可设为每 30 分钟 / 每小时 / 每 6 小时 / 每天自动巡检一次，出现新的严重问题时弹出提醒

**AI 运维助手（自我学习机制参考 Hermes Agent，并针对多服务器运维做了扩展）**
- 默认使用 DeepSeek 官方接口（`https://api.deepseek.com`，模型 `deepseek-v4-pro`，可换成 `deepseek-flash`），填上 API Key 就能用；也支持 Claude（Anthropic 官方 Go SDK）以及通义千问、Kimi、智谱、OpenAI、Ollama 等 OpenAI 兼容接口
- 终端里的「AI 运维」：在终端旁边直接对话，AI 默认只操作当前这台服务器，能读取终端里刚才的输出；回复里的命令可以一键填入终端。每台服务器各有自己的对话，也可以在「AI 助手」页面继续
- 可以把图片和文件发给 AI：点输入框左下角的回形针选择，直接粘贴截图（Ctrl+V），或者把文件从资源管理器拖进对话，一条消息最多 10 个
  - 图片（截图、报错的照片）随消息发给模型，需要模型支持图片输入（Claude、通义千问 VL、GLM-4V、GPT-4o 等）。模型不支持时照常回复，并在对话里说明图片没有发出去。图片会缩到长边 2000 像素以内，在数据目录里保存一份（`data\attachments`），删除对话时一起删除
  - 文件留在原来的位置，不复制：较短的文本文件（配置、脚本）内容直接附在消息里，较长的（日志）由 AI 分段阅读；安装包、压缩包这类文件，AI 可以传到服务器上再解压、安装——上传前会弹出审批卡片，写明本地文件和服务器上的目标位置
- 22 个工具：执行命令、读写文件、查看终端内容、采集状态、服务管理、证书查看与部署、添加和修改证书的部署目标、脚本执行与保存、巡检、记忆、长期记忆检索、技能、会话检索、阅读附件、把附件上传到服务器
- 让 AI 部署证书时不用自己去「证书」页填部署目标：告诉它部署到哪台服务器、哪个服务，它会先查清服务实际读取的证书路径，再添加（或修改）部署目标并部署。审批卡片上写明证书和私钥放在哪里、部署后重载哪个服务，同意一次即可；私钥由程序直接写到服务器上，不经过模型
- 命令风险分级：只读命令可自动执行；修改类操作弹出审批卡片；高危命令（删除系统目录、关机、停止 SSH、覆盖 authorized_keys 等）总是需要确认；读取私钥等敏感文件也需要批准
- 自我学习：

| 机制 | 说明 |
|---|---|
| 核心记忆 MEMORY.md / USER.md | 整个环境通用的约定与用户偏好，条目以 § 分隔，容量很小（每次对话都完整带上），AI 用 add / patch / remove 自行维护；会话开始时冻结注入系统提示词 |
| 长期记忆 | 不限容量的知识库：具体到某台服务器的事实（角色、路径、已知问题及根因）都存在这里，并标注是哪些服务器。核心记忆快满时，AI 把不常用的条目移到长期记忆而不是删掉 |
| 往期对话要点 | 每一轮对话结束后，程序自动把“问题 → 操作 → 结论”存入长期记忆，不需要再调用一次模型；升级后会为已有的历史会话补建 |
| 自动召回 | 每次提问前，按相关度找出几条长期记忆、往期对话要点和相关技能，附在用户消息后面（不改动系统提示词，不影响提示词缓存）。在当前服务器的终端里提问、或问题里提到某台服务器时，标注了它的记忆优先。对话里可以点开「已参考 N 条长期记忆」查看；同一条在一个会话里只带一次 |
| 向量模型 | 长期记忆按“意思”检索：单独配置一个 OpenAI 兼容的 /embeddings 接口（预设阿里云百炼的通义千问向量模型、硅基流动、智谱、火山方舟、OpenAI、Ollama）。不同模型的相似度分布不同，程序先用几组样例量出这个模型的分布再定相关度下限。没有配置或接口出故障时自动退回内置的关键词匹配（不联网） |
| 技能 SKILL.md | 程序性记忆（兼容 agentskills.io 格式），AI 完成复杂任务、踩坑或被纠正后沉淀为技能，使用时发现更好的做法会 patch 更新；系统提示只包含索引，正文按需读取 |
| 技能整理 | AI 沉淀的技能超过 30 天没用到会标记“久未使用”，超过 90 天自动归档（不再占用技能索引，可以恢复）；可以固定某个技能，固定后不会被归档，AI 也不能删除它 |
| 会话检索 | 按关键词检索历史对话的原始记录，查看当时的命令和输出 |
| 上下文压缩 | 对话超出上下文预算时，被丢弃的各轮会留下一行“问题 → 结论”，而不是直接消失 |
| 定期提醒 | 每隔若干轮提醒 AI 回顾是否有值得保存的知识 |
| 后台复盘 | 一轮对话中工具调用较多时，自动让 AI 复盘并写入记忆与技能（复盘时会对照相关的长期记忆，避免重复）；也可手动点击「学习复盘」 |
| 安全过滤 | 拒绝写入密码、密钥、大段原始数据和疑似提示注入的内容；带有密码、密钥的消息不会发给向量接口 |

## 快速开始

1. 从本仓库的 Releases 页面下载 `QianYeSSHPilot-<版本>.exe`，放进一个单独的文件夹后双击运行（数据会保存在它旁边的 `data` 文件夹里）；自己编译的话产物在 `build\bin`。Windows 10/11 自带 WebView2，缺失时会自动引导安装
2. 仪表盘顶部的「快速上手」会一步步带你完成：添加服务器 → 准备密钥 → 巡检 → 导入证书 → 配置 AI
3. 「设置 → AI 模型」里填写 DeepSeek 的 API Key（或换成其他服务商），即可使用 AI 助手和终端里的「AI 运维」
4. （可选）「设置 → 长期记忆」里填写向量模型的 API Key（默认预设是阿里云百炼的 `text-embedding-v4`），长期记忆就能按意思检索；不填也能用，只是按关键词匹配

**数据位置**：默认在程序所在目录下的 `data` 文件夹，导出的加密备份默认保存到旁边的 `backup` 文件夹——移动程序时请连同 `data` 一起移动。程序所在目录不能写入时（例如放在 Program Files 里）退回 `%AppData%\SSHPilot`；也可以用环境变量 `SSHPILOT_DATA_DIR` 指定数据目录（使用不同数据目录的实例可以同时运行）。

1.3 及更早的版本把数据放在 `%AppData%\SSHPilot`：第一次用新版本启动时，如果程序目录下还没有 `data`，会把旧目录里的数据（连同界面偏好）复制过来，旧目录里的数据原样保留，确认无误后可以自己删除。

密码、私钥、API Key 使用 Windows DPAPI 加密（只有这台电脑上的当前 Windows 用户能解密），所以直接拷贝 `data` 文件夹到另一台电脑带不走这些密钥；迁移到其他电脑请使用「设置 → 数据与备份」导出加密备份（scrypt + AES-256-GCM）。

**启动密码**（「设置 → 安全」，默认不开启）：

- 设置后，打开程序要先输入密码；标题栏右上角的锁可以随时把界面锁上，也可以设成电脑空闲几分钟后自动锁定。锁定只是挡住界面，正在运行的终端和任务不会中断，已经打开的文件管理窗口会先收起来
- 它不只是一道门：保存的服务器密码、sudo 密码、代理密码、私钥、证书私钥和 API Key 会用启动密码再加密一层（随机数据密钥 + AES-256-GCM，数据密钥由启动密码经 scrypt 派生的密钥加密后放在 `data\lock.json`）。没有输入密码时这些内容在内存里也是密文，程序不会连接任何服务器；别人拿到 `data` 文件夹、甚至登录了同一个 Windows 账户，没有启动密码也解不开
- 服务器列表（地址、用户名）、脚本、对话记录和 AI 的记忆不加密，只是被锁屏挡住
- 连续输错 5 次后需要等待（30 秒起，逐次翻倍），重启程序不会清零
- **忘记密码无法找回**：只能在锁屏上「重置」，重置会清空上面那些密码和密钥，服务器列表等其他数据保留。重置前的数据会留一份副本（`data\store.json.before-reset` 和 `data\lock.json.before-reset`），以后想起密码，关闭程序后把这两个文件改回原名即可恢复。建议设置启动密码前先导出一份加密备份
- 不要删除 `data\lock.json`（旁边的 `lock.json.bak` 是它的备份）：没有它，加密的密码和密钥就解不开了
- 设置启动密码后不要再用 1.4 及更早的版本打开同一份数据：旧版本不认识启动密码，会把密文当成密码去登录服务器
- 从 1.3 及更早版本升级上来的用户：旧数据目录 `%AppData%\SSHPilot` 里还留着升级时的那份数据，它不受启动密码保护，确认新版本正常后请自己删除（「设置 → 安全」里有提示和打开按钮）

## 从源码构建

环境：Go 1.27+、Node.js 22+、Wails CLI v2.17

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.1
```

```bash
wails build -platform windows/amd64 -webview2 embed -trimpath -ldflags "-s -w"
```

产物位于 `build/bin/QianYeSSHPilot.exe`。

> 不要加 `-clean`：它会清空整个 `build/bin`。直接从 `build/bin` 运行程序时，数据就保存在 `build/bin/data` 里，会被一起删掉。程序正在运行时也无法覆盖 exe，可以用 `-o 其他文件名.exe` 另存。
